小学生のためのオンラインゲーム教室

ゲームの通信つうしんって、どうなっているの？

遠くにいる友だちと同じゲームで遊べるのは、コンピューターどうしが、小さな「お手紙」をものすごい速さで送り合っているからです。

まず、ひとことで言うと

オンライン対戦は、「自分がしたことを知らせる」 → 「みんなの今のようすを受け取る」、を何度もくり返しています。
✉️

送るお手紙

「右へ動いた」「鉄砲をうった」「戦車に乗った」など、自分がしたことを送ります。

📬

もらうお手紙

「みんなはここにいる」「点数は3対2」など、ゲームの今のようすを受け取ります。

① まず、ゲームを受け取る

GitHub Pagesは「ゲームを置いておく本だな」です。AさんとBさんは、同じゲームを自分のコンピューターに読みこみます。

「どうつなぐ？」と「だれが決める？」

この2つは、べつの問題です。道路としんぱんを分けて考えると、わかりやすくなります。

つなぎ方① P2P

友だちのコンピューターへ、できるだけ直接お手紙を送ります。近道ですが、家のネットの門が通れないことがあります。

または

つなぎ方② サーバーを通す

まん中のサーバーが、お手紙の受けわたしをします。少し遠回りですが、つながりやすくなります。

決め方① ホストがしんぱん

1人のコンピューターが、「当たった」「点が入った」を決めます。その人がゲームを閉じると、対戦も止まりやすくなります。

決め方② サーバーがしんぱん

サーバーがみんなのそうさを見て、正しい結果を決めます。だれか1人がぬけても、試合を続けやすくなります。

GitHub Pagesだけでは、しんぱんはできない

GitHub Pagesの仕事

ゲームの絵やプログラムを、みんなへ配ること。

図書館が、同じルールブックをみんなへ貸すイメージです。

対戦サーバーの仕事

試合中のお手紙を受け取り、部屋と結果を管理すること。

運動場で、しんぱんが試合を見ているイメージです。

直接つながらないときは、どうするの？

家や学校のネットには、知らない通信を止める「門」があります。P2Pの近道が通れないときは、TURN（ターン）という中つぎ所を使います。

TURNは、山道が通れないときに使う「う回路」のようなものです。

通信がうまくいかない4つのわけ

  • 道が見つからない： ネットの門がP2Pを止めている。TURNなどのう回路が必要です。
  • ホストがお休みする： ホストの画面を閉じたり、別のタブへ移ったりすると、ゲームの計算が遅くなることがあります。
  • お手紙の順番がわからない： 番号がないと、新しい位置のあとに古い位置を使ってしまうことがあります。
  • お手紙が届くまで時間がかかる： 遠い場所を通るほど、ボタンを押してから画面に出るまでの「ラグ」が大きくなります。

じょうずな通信にする4つのくふう

小さく送る
必要な情報だけを、短いお手紙にします。
番号をつける
新しいお手紙と古いお手紙を見分けます。
つなぎ直せる
少し切れても、同じ部屋へもどれるようにします。
ひみつを守る
パスワードや大切なカギを、ゲームの中へそのまま置きません。
