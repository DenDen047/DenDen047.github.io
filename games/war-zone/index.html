戦い方（サバイバル）

4軍による同時戦です。基地を破壊された軍はそれ以降いっさい復活できません。生き残っている兵士は戦い続けられますが、倒されたらその軍は脱落。最後まで残った1軍の勝ちです。だから自分の基地を守ることが何より大事で、逆に敵の基地さえ落とせば、あとは残党を掃討するだけになります。オンラインでは同じチームを選んだ人同士が味方になります。

キャラクター

キャラクターごとに持てる武器が決まっています。数字キーの1〜3は、そのキャラの装備の1番目〜3番目に対応します。

  • 🎖️ 兵士 … アサルトライフル / ハンドガン / 銃剣。撃ち合いに強い標準型。
  • ⚔️ 侍 … 打刀 / 戦斧 / コンバットナイフ。銃は一切持てませんが、体力＋30・移動速度＋18%・近接ダメージ1.4倍で、パリィの受付も長め。懐に飛び込むのが仕事です。
  • 🪤 罠師 … サブマシンガン / ショットガン / 軍用シャベル。地雷を5個持ち、その地雷は敵からほとんど見えません。敵の地雷も見抜けて、有刺鉄線（Cキー）で敵の足を止められます。そのぶん体力は低めです。
  • 🚀 重火器兵 … ロケットランチャー / スナイパー / ハンドガン。ロケット弾は弾速が遅くて避けられますが、当たれば戦車や基地を大きく削ります。足は遅く、接近戦は苦手です。

乗り物と銃座

戦車は120mm主砲（爆発・対戦車）と同軸機関銃（連射・対歩兵）を積んでいます。数字キーかホイール（スマホは「武器」ボタン）で切り替えてください。

機関銃座はマップ上に8つ置かれた中立の設備です。近づいてEキー（スマホは「戦車」ボタン）で取り付けます。動けなくなる代わりに、連射の効く重機関銃を撃て、防盾のおかげで被弾も半分になります。誰でも先に取り付いた者が使えるので、要所の銃座は奪い合いになります。

隠れる：敵は壁やコンテナの裏にいる相手を見つけられず、正面の視野角の外も見えません。茂みは通り抜けられるのに視線を遮るので、待ち伏せに最適です。ただし至近距離まで近づくと向きに関係なく気づかれます。走ると足音が響くので、忍び寄るときは歩きましょう。

昼と夜：時間が進むと朝→昼→夕方→夜と移り変わります。夜は視界がぐっと狭まるので奇襲のチャンス、昼は遠くまで見渡せます。

地雷：足元に設置すると約1秒後に作動し、踏んだ敵を吹き飛ばします。味方には見えますが、敵にはすぐ近くに来るまで見えません。戦車にも大ダメージ。

攻撃直前に盾を構えるとパリィ成功。銃弾は敵へ跳ね返し、近接武器や軍用犬の攻撃は相手をひるませます。パリィ受付は短く、成功後も約1秒の再使用待ちがあります。通常の盾防御は正面攻撃を軽減しますが、構え中は攻撃不可・移動速度低下。防弾鎧と盾はフィールド装備または基地で補給できます。
