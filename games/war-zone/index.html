    戦い方（サバイバル）

    4軍による同時戦です。基地を破壊された軍はそれ以降いっさい復活できません。生き残っている兵士は戦い続けられますが、倒されたらその軍は脱落。最後まで残った1軍の勝ちです。だから自分の基地を守ることが何より大事で、逆に敵の基地さえ落とせば、あとは残党を掃討するだけになります。オンラインでは同じチームを選んだ人同士が味方になります。

    キャラクター

    キャラクターごとに持てる武器が決まっています。数字キーの1〜3は、そのキャラの装備の1番目〜3番目に対応します。

    • 🎖️ 兵士 … アサルトライフル / ハンドガン / 銃剣。撃ち合いに強い標準型。
    • ⚔️ 侍 … 打刀 / 戦斧 / コンバットナイフ。銃は一切持てませんが、体力＋30・移動速度＋18%・近接ダメージ1.12倍で、パリィの受付も長め。懐に飛び込むのが仕事です。打刀は構え方で技が変わります：走りながら斬ると正面の1体を斬る通常攻撃、足を止めて斬ると全方位の範囲攻撃になり、まわりを囲む敵をまとめて薙ぎ払えます（間合いも少し広がる代わりに、1体あたりの威力は下がります）。さらに足を止めて振っている間は、飛んできた銃弾を刀で弾き返します。囲まれたら止まって振る、追うときは走りながら振る、と使い分けてください。
    • 🪤 罠師 … サブマシンガン / ショットガン / 軍用シャベル。地雷を5個持ち、その地雷は敵からほとんど見えません。敵の地雷も見抜けて、有刺鉄線（Cキー）で敵の足を止められます。そのぶん体力は低めです。
    • 🚀 重火器兵 … ロケットランチャー / スナイパー / ハンドガン。ロケット弾は弾速が遅くて避けられますが、当たれば戦車や基地を大きく削ります。足は遅く、接近戦は苦手です。

    ステージ「練習場」

    はじめての人のための訓練施設です。敵兵はいません。マップの中央に的が並んでいて、撃っても撃ち返されません。壊した的は数秒で立て直るので、何度でも練習できます。

    画面の左に練習メニューが出ます。案内された操作をそのとおりにやると、次の項目へ進みます。移動・射撃・リロード・武器の持ちかえ・グレネード・地雷・盾・機関銃座・戦車・基地での補給まで、ひととおり試せば本番のステージで困りません。うまくいかない項目は「この項目をとばす」で先に進めます。

    中央には動く的とドラム缶もあります。動く的は少し先を狙うと当たります。ドラム缶は撃つと爆発するので、近くにいると自分もダメージを受けます。勝ち負けはないので、飽きたらメニューから本番のステージへどうぞ。

    ステージ「時の森」

    薄明かりの森です。マップの中央にある岩に、剣が1本だけ刺さっています（ミニマップに剣の印が出ます）。岩に近づいて E キー（スマホは「アクション」ボタン）を5秒間押し続けると剣が抜けます。途中で手を離すと戻ってしまうので、安全を確かめてから抜きましょう。

    抜いた時の剣は、森が育てた聖剣です。持っているあいだ、自分の近くに飛んできた銃弾は時間が止まったようにゆっくりになります。ゆっくり流れてくる弾は歩いてよけられるので、そのまま相手の懐へ踏み込めます。剣は倒されても失いません。

    森には魔物が棲んでいます。銃でも倒せますが体力が非常に高く、削り切るには時間がかかります。ところが時の剣で叩けば一撃で倒せます。魔物はどの軍の兵士も襲うので、他の軍との戦いの最中に出くわさないよう気をつけてください。

    ステージ「暗黒の森」

    夜が明けない密林のステージです。木と茂みが密生していて視界はほとんど利きません。そしてこの森にはクリーチャーが1体だけ棲んでいます。

    クリーチャーは音に反応します。Shift でダッシュすると足音が響いて気づかれ、銃を撃つとさらに遠くから寄ってきます。歩いている限りは、すぐ近くまで行かないかぎり見つかりません。

    倒すことはできません。どんな武器も効かないので、見つかったら逃げるしかありません。そして触れられたら一撃で死にます。追われている間は画面の縁が赤く脈打ち、ミニマップに赤い点が出ます。走って逃げれば足音でずっと追われるので、遮蔽に隠れて歩いて撒くのが賢いやり方です。

    乗り物と銃座

    戦車は120mm主砲（爆発・対戦車）と同軸機関銃（連射・対歩兵）を積んでいます。数字キーかホイール（スマホは「武器」ボタン）で切り替えてください。

    機関銃座はマップ上に8つ置かれた中立の設備です。近づいてEキー（スマホは「アクション」ボタン）で取り付けます。動けなくなる代わりに、連射の効く重機関銃を撃て、防盾のおかげで被弾も半分になります。誰でも先に取り付いた者が使えるので、要所の銃座は奪い合いになります。

    ロボットは拠点の🤖 ロボット格納庫で組み立てる、自分だけの1機です。試合が始まると自軍基地のわき（戦車とは反対がわ）に配備されます。近づいてEキー（スマホは「アクション」ボタン）で乗り込め、もう一度押すと降ります。乗っている間の体力はロボットの装甲になり、攻撃は左右の腕に付けた武器で行います。武器切替（1〜3キー・ホイール、スマホは「武器」ボタン）で右腕と左腕を持ち替えます。壊されても数秒で基地のわきに戻ってきます。

    自分が乗っていないあいだ、ロボットは戦車と同じように自分で敵を探して戦います。硬い相手には一撃の重い腕、生身の相手には手数の多い腕、と勝手に持ち替え、射程の短い腕なら間合いまで踏み込みます。前線に置いておくだけでも仕事をしてくれます。

    隠れる：敵は壁やコンテナの裏にいる相手を見つけられず、正面の視野角の外も見えません。茂みは通り抜けられるのに視線を遮るので、待ち伏せに最適です。ただし至近距離まで近づくと向きに関係なく気づかれます。走ると足音が響くので、忍び寄るときは歩きましょう。

    昼と夜：時間が進むと朝→昼→夕方→夜と移り変わります。朝のあいだは夜明けの光で戦場全体が見渡せ、敵の位置がすべて分かります。昼は遠くまで見通せ、夜は視界がぐっと狭まるので奇襲のチャンスです。

    降下：試合はソロ戦のとき、輸送機からのパラシュート降下で始まります。降りている間は攻撃も被弾もできませんが、移動キーで少しだけ流されるように動けます。着地したところが最初の位置になります。

    拠点（ショップ・作業台・鍛冶場・格納庫・徴兵ガチャ）

    メニューの「🏕 拠点へ」から、自分の陣地を歩き回れます。WASD / 矢印キーで歩き、建物の入口に近づいて E キー（スマホは「アクション」ボタン）を押すと中に入れます。試合の結果画面からも直接行けます。

    • 🏪 補給ショップ … 5つのタブに分かれています。強化は最大HPや装甲などの底上げ、武器は新しい銃・弓・近接武器、部品はアタッチメント、塗装は武器の色、矢は弓で撃つ矢です。お金（G）は試合に勝つとたまります。
    • 🔧 作業台 … 買ったアタッチメントを武器に取り付け、好きな色に塗るところです。武器を選ぶと、取り付けで数値がどれだけ変わるかが緑（良くなる）と赤（悪くなる）で出ます。一度買った部品は、何度でもどの武器にも付け替えられます。
    • ⚒ 鍛冶場 … 廃材と所持金で鎧を作ります。廃材は試合で敵を倒すとたまります。兜・胴鎧・具足の3部位があり、それぞれ1つ装備できます。上の段の鎧は、下の段を作ってからでないと作れません。
    • 🎲 徴兵所 … チケットで新しいキャラクターを引きます。チケットは試合に勝つともらえ、お金でも買えます。すでに仲間のキャラが出たら練度が上がり、そのキャラの最大HPと攻撃力が5%ずつ伸びます（最大5回）。仲間にしたキャラの装備武器は、買わなくても使えるようになります。
    • 📋 編成テント … 出撃するキャラクターと、持っていく3つの武器を決めます。数字キーの1〜3がこの並び順に対応します。侍のような近接専門のキャラは銃を選べません。
    • 🤖 ロボット格納庫 … 自分のロボットを組み立てます。フレーム（体力・速さ・脚の形）、カラー（色）、右腕 / 左腕（武器）をそれぞれ選べて、機体名も付けられます。プレビューがゆっくり回るので、いまの見た目をそのまま確かめられます。フレームと腕は所持金と廃材で作り、カラーは所持金だけで買えます。組んだ機体は格納庫のわきに駐機するので、拠点でも乗って動かせます。
    • 🚩 出撃ゲート … メニューへ戻ります。

    アタッチメント

    銃と弓には照準器・銃身・弾倉・下部レールの4か所に部品を付けられます（近接武器には付きません）。同じ場所には1つだけです。

    • 🔴 ドットサイト / 🔭 倍率スコープ / 📡 レーダー（照準器）… レーダーは半径620以内の敵を、壁の裏にいてもミニマップに映します。ミニマップに青い輪が出ているときは効いています。
    • 🤫 サプレッサー / 🔩 ヘビーバレル / 🔥 マズルブレーキ（銃身）… サプレッサーを付けると銃声が消え、撃っても位置がバレません。
    • 📦 拡張マガジン / ⚡ クイックマグ / 🛡 徹甲弾（弾倉）… 装弾数・リロードの速さ・貫通が変わります。
    • 🔫 アンダーバレルSMG / 🔺 レーザーサイト / 🖐 フォアグリップ（下部レール）… アンダーバレルSMGは撃つたびに9mm弾をもう1発おまけで発射します。弾も矢も減りません。

    弓と矢

    軍用弓とクロスボウはショップで買えます。弾倉ではなく矢を消費し、撃っても音がしないので位置がバレません。矢もショップで10本ずつ買い、出撃するときに矢筒の容量ぶんだけ持ち出します。撃たずに残った矢は帰ってくると戻ります。

    矢は3種類あります。標準矢は安く、貫通矢は敵を2体多く貫き、爆裂矢は当たると爆発して戦車や基地にも効きます。どれを持っていくかは編成テントで選びます。矢筒の容量はショップの大型矢筒で増やせます。試合中に矢が足りなくなったら、自分の基地に戻ると残っている矢を補給できます。試合が終わるたびに標準矢が8本支給されるので、矢が尽きて何もできなくなることはありません。

    二丁拳銃と二刀流

    ショップで買える二丁拳銃は、撃つたびに右手と左手が入れ替わります。1発は軽いぶん手数が多く、近〜中距離の撃ち合いで押し切る武器です。

    二刀流は二本の刀を交互に振る近接武器です。振るたびに右手と左手が入れ替わり、振っている間は正面に飛んできた銃弾や矢を斬り落とします。斬った弾はその場で消えるので、撃たれながら前へ出るのに使えます。

    この2つだけを装備しているのが、徴兵ガチャの★5🖤 黒衣の傭兵 ヴァンタです。全身黒ずくめの覆面で、傷の治りが2.6倍速く、足も速い接近戦向きのキャラクターです。

    ミッションと実績（メダル）

    「1試合で20体倒す」「暗黒の森で勝つ」といったミッションがあり、達成するとメダルがもらえます。集めたメダルはメニューの「🎖 実績（メダル）」に貯まっていきます。まだ取っていないメダルも条件が見えるので、次の目標にしてください。練習場での戦果は数えません（訓練のメダルだけは練習場で取れます）。

    スキン

    メニューのスキンで自分の見た目を変えられます。強さはいっさい変わりません。迷彩のほかに、半透明で走査線が流れるホログラム兵、発光ラインが走るネオングリッド、バイザーが光るクロムメック、ブロック体のボクセルといったSF系もあります。

    地雷：足元に設置すると約1秒後に作動し、踏んだ敵を吹き飛ばします。味方には見えますが、敵にはすぐ近くに来るまで見えません。戦車にも大ダメージ。

    攻撃直前に盾を構えるとパリィ成功。銃弾は敵へ跳ね返し、近接武器や軍用犬の攻撃は相手をひるませます。パリィ受付は短く、成功後も約1秒の再使用待ちがあります。通常の盾防御は正面攻撃を軽減しますが、構え中は攻撃不可・移動速度低下。防弾鎧と盾はフィールド装備または基地で補給できます。
