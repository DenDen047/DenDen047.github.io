操作方法

PC

  • WASD … 移動
  • マウス … 照準
  • 左クリック長押し … 射撃
  • R … リロード
  • G … グレネードを投げる
  • E … 戦車に乗る / 降りる
  • Q … 攻撃直前に押してパリィ / 長押しで防御
  • 1〜6 / ホイール … 武器切替（6はナイフ）
  • Shift … ダッシュ

スマホ

  • 左スティック … 移動
  • 右スティック … 照準＆自動射撃
  • 💣 投げる … グレネード
  • 戦車 … 近くの戦車に乗る / 降りる
  • 🛡 盾 … 攻撃直前に押してパリィ / 長押しで防御
  • リロード / 武器 … 右下ボタン

攻撃直前に盾を構えるとパリィ成功。銃弾は敵へ跳ね返し、ナイフや軍用犬の攻撃は相手をひるませます。パリィ受付は短く、成功後も約1秒の再使用待ちがあります。通常の盾防御は正面攻撃を軽減しますが、構え中は攻撃不可・移動速度低下。防弾鎧と盾はフィールド装備または基地で補給できます。視界外の足音はオレンジ色の波紋で察知できます。敵基地の耐久力を0にした軍の勝ちです。
