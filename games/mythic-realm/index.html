    冒険の大地（おすすめ）

    12の土地がひと続きになった世界です。決まったステージを1つずつ攻略するのではなく、辺境の村を出て自分の足で歩き回ります。画面の端まで進むと、そのまま隣の土地へ移ります。土地ごとに地形・明るさ・出てくる魔物が変わり、いちど作られた地形と宝箱は戻ってきても同じままです。

    • 世界地図 … Mキー（スマホはミニマップを押す）。行った土地だけが地図に描かれます。
    • 宝箱 … 各地に隠れています。近づいてE（スマホは「🎁 調べる」）。金貨・命の器（最大体力 +20）・魔力の秘薬・旅の道具袋が入っています。位置はミニマップに光って出ます。
    • 辺境の村 … 唯一勇者の祭壇がある土地です。円の中に入れば体力・鎧・盾が回復し、道具も補給できます。
    • ボスの棲む土地 … 崩れた神殿（炎竜イグニス）と常闇の樹海（魔狼王フェンリル）には魔界の門があります。門を壊すとボスが現れ、倒すと紋章の宝箱を落とします。
    • 魔王の玉座 … 炎の紋章と氷の紋章がそろうまで封印されていて入れません。両方そろえて魔王を討てば冒険は終わりです。
    • 倒れても終わりません … 力尽きると村の祭壇で目を覚まします。集めたものとレベルはそのまま残ります。

    戦い方（章立ての戦場）

    勇者パーティ vs 魔物の軍勢です。プレイヤー同士は戦いません。マップの反対側にある魔界の門から魔物が次々と湧いてくるので、門を攻撃して壊しましょう。門が砕けると増援は止まり、代わりに奥からそのステージのボスが現れます。ボスと残った魔物をすべて倒せば勝ちです。

    自分たちの拠点は勇者の祭壇です。倒れてもここから復活できますが、祭壇を壊されるとそれ以降いっさい復活できません。生き残りが全員倒れたら負けです。祭壇の円の中に入ると体力・鎧・盾が回復し、マナ・矢・火炎瓶・呪印も補給できます。

    門の体力が減るほど、湧いてくる魔物が強くなります。最初はゴブリンだけですが、やがてオーク・骸骨の射手・闇術師・石のガーゴイルが混ざってきます。ギルドで一緒に挑むときは、参加者全員が同じパーティの仲間になります。

    ギルド（みんなで挑む）

    メニューの🏰 ギルドから、友達と同じ戦場へ入れます。サーバーは要りません（ブラウザ同士のP2P）。

    • ギルドを作る … 押すとあなたがホストになり、ギルド番号（4文字）が発行されます。この番号を仲間に伝えてください。
    • ギルドに入る … 教わった番号を入力欄に入れて押すと、ホストへ参加を申し込みます。
    • 入れるかどうかはホストが決めます … 申し込みがあると、ホストの画面に名前と職業が出て「入れる / 断る」を選べます。入れた人だけがパーティの席に着きます。
    • 出発 … ホストが「ギルドがそろった → 出発」を押すと、3秒のカウントダウンのあと全員で戦場へ出ます。空いた席はCPUの仲間が務めます。

    章立て（3つの章）

    本編は第1章 古代遺跡 → 第2章 常闇の樹海 → 第3章 魔界の順に進みます。前の章をクリアすると次の章が選べるようになり、章が進むほど出てくる魔物の顔ぶれが変わって強くなります（体力・攻撃力が第2章で1.3倍、第3章で1.7倍）。クリアの記録はこのブラウザに残ります。

    魔界では魔物が桁違いに強い代わりに、魔界の加護で勇者側も底上げされます（最大HP +25%、攻撃力 +15%、足も少し速く）。新しい属性の毒と竜が出てくるのもこの章からで、クリアすると新職業竜騎士が選べるようになります。地面のあちこちに溶岩だまりがあり、敵味方どちらが踏んでも焼かれます。

    破壊の森は章に属さない特別なステージで、いつでも遊べます。

    章立ての戦場は1戦で決着がつく腕試しです。じっくり探索したいときは冒険の大地を選んでください。冒険を踏破すると、すべての章と職業がまとめて解放されます。

    属性の相性

    武器には属性があり、相手のまとう属性との組み合わせでダメージが変わります。同じ属性どうしはほとんど効きません（0.1倍）。炎竜イグニスに火球を撃ってもかすり傷にしかならないので、氷や雷に持ちかえましょう。

    • 🔥 炎 … ❄️氷に1.8倍。🔥炎の相手には0.1倍、🐲竜にも通りにくい。
    • ❄️ 氷 … 🔥炎に1.8倍、🐲竜に1.3倍。❄️氷の相手には0.1倍。
    • ⚡ 雷 … ❄️氷に1.4倍。⚡雷の相手には0.1倍。
    • ✨ 聖 … 🌑闇に1.8倍、🐲竜に1.5倍、🧪毒に1.4倍。アンデッドはたいてい闇なのでよく効きます。
    • 🌑 闇 … ✨聖に1.8倍。🌑闇の相手には0.1倍。
    • 🧪 毒 … 属性を持たない生きものに1.3倍。✨聖には通りにくい。
    • 🐲 竜 … 属性なしに1.25倍、❄️氷に1.4倍。✨聖には通りにくい。

    自分の攻撃が「効果がうすい」「効果ばつぐん」のときは、画面中央に短く出ます。武器名の左のアイコンがその武器の属性です。

    魔力（魔法使い・闇魔導士）

    この2つの職業だけは魔力を使って魔法を撃ちます。魔力は撃つと減り、放っておいても毎秒7ずつ戻ります。強い魔法ほど多く食べるので（火球30、闇の槍24、雷撃11、呪詛6、氷の矢5）、撃ちっぱなしにはできません。

    フィールドに落ちている🧿 魔力の秘薬を拾ってVキー（スマホは「🧿 秘薬」）で飲むと、7秒間だけ戻りが毎秒30まで速くなります。3つまで持てます。ここぞという場面で飲みましょう。

    溜め撃ち（狩人の長弓）

    長弓はクリックを押している長さで放つ矢の本数が変わります。ぱっと離すと1本、少し引き絞ると2本、いちばん長く引き絞ると3本を扇状に放ちます。引き絞り具合は画面右下に出ます。速射弓はこれまでどおり押しっぱなしで連射です。

    必殺技

    職業ごとに必殺技が1つあります。X キー（スマホは「⚡ 必殺」ボタン）で撃つと、十数秒の待ち時間に入ります。待ち時間の残りは画面右下と、スマホではボタンの数字に出ます。ゴーレムや魔導砲台に乗っている間は撃てません。

    • 🌪 烈風斬（剣士）… 前へ踏み込みながら三連の斬撃。通り道の敵をまとめて斬り払います。
    • 💥 エクスプロージョン（魔法使い）… 前方に魔力を集めて詠唱します。詠唱の間、まわりの敵をすべて爆心へ引きずり寄せ、そのうえで起爆します。当たった障害物も跡形なく吹き飛びます。詠唱中は動けず、撃ったあとは力尽きて少しのあいだ動けません。
    • 🏹 千矢の雨（狩人）… 狙った一帯へ約2秒間、矢を降らせ続けます。逃げ遅れた敵を止まらず削ります。
    • 🕊 聖域（僧侶）… 自分を中心に光の輪を6秒張ります。中の味方は回復し受けるダメージも減り、中の敵は聖なる光に焼かれます（アンデッドには特に効きます）。輪は僧侶についてきます。
    • 🐉 龍波斬（冒険者）… 剣を敵へ突き立て、その切っ先から龍の姿をした波動を放ちます。波動は敵を貫いてまっすぐ走り抜けます。一撃が重いぶん待ち時間も長め（30秒）。
    • 🌑 暗黒領域（闇魔導士）… 前方に闇の淵を開きます。中の敵は闇に焼かれて足が鈍り、吸い取った命が術者の傷をふさぎます。
    • 🐲 竜炎の息吹（竜騎士）… 竜の息を前へ吐き続けます。扇の中の敵を焼き、通ったあとの地面はしばらく燃え続けます。
    • 🐺 獣王の咆哮（獣使い）… 倒れた狼を呼び戻して立ち上がらせ、9秒間だけ荒ぶらせます（速く走り、強く噛みます）。近くの敵はすくみ上がって動けなくなります。
    • 🗿 震天の一撃（魔神像）… 地面を叩き割ります。広がる衝撃波が敵を吹き飛ばし、しばらく起き上がれなくします。

    職業

    職業ごとに見た目と持てる武器が決まっています。数字キーの1〜3は、その職業の武器の1番目〜3番目に対応します。

    • ⚔️ 剣士 … 長剣 / 大剣 / 短剣。体力がいちばん高く、近接ダメージ1.35倍。パリィの受付も長めで、前に出て敵を引きつける役です。
    • 🔮 魔法使い … 火球 / 雷撃 / 氷の矢。魔法の威力1.35倍。火球は着弾して爆発、雷撃は敵を貫通、氷の矢は当たった敵の足を鈍らせます。体力は最も低いので後ろから撃ちましょう。
    • 🏹 狩人 … 長弓 / 速射弓 / 狩猟ナイフ。弓の威力1.25倍で足も速い。呪印の罠を4枚持ち、敵の罠も見抜けます。茨の呪縛（Cキー）で敵の足を止められます。
    • ✨ 僧侶 … 聖光 / 癒しの光 / 聖なる槌。癒しの光で味方の傷をふさげる唯一の職業です。聖属性は骸骨や闇術師などのアンデッドに1.8倍のダメージを与えます。
    • 🗡️ 冒険者 … 片手剣 / 速射弓 / 投げ斧。近接も遠距離もそこそこ扱える万能型。火炎瓶4個・呪印3枚と道具が豊富で、どんな場面でも仕事があります。
    • 🌑 闇魔導士 … 闇の槍 / 呪詛 / 魂喰らい。自分が闇属性なので闇の攻撃はほとんど効きませんが、聖なる力には脆いです。鎌「魂喰らい」で斬ると与えたダメージの35%を吸って回復します。魔力を使う職業です。
    • 🐲 竜騎士 … 竜槍 / 竜牙弾 / 片手剣。魔界編をクリアすると選べるようになる前衛。体力が高く、竜属性は属性なしの相手にも氷にもよく通ります。
    • 🐺 獣使い … 槍 / 獣の鞭 / 投げ斧。狼を2匹つれて戦います。狼は勝手に敵へ噛みつき、倒されてもしばらくすると戻ってきます。槍はリーチが長く、鞭はさらに長く広く払えます。
    • 🗿 魔神像 … 岩の拳のみ。武器をいっさい持てませんので、剣も弓も魔法も使えず、数字キーでの持ちかえもありません。その代わり体力は剣士の1.5倍以上あり、一撃が重く正面を広く払えます。ただし拳は連打が効かず、足も全職業でいちばん遅い。体が大きいぶん敵の矢や魔法にも当たりやすいうえ、狭い場所は通り抜けられません。

    魔物とボス

    • ゴブリン … 素早いが弱い。数で押してきます。
    • オーク … 棍棒を振り回す重量級。体力が高く、まともに殴られると痛い。
    • 骸骨の射手 … 骨の矢を撃ってくるアンデッド。聖属性が効きます。
    • 闇術師 … 闇弾を飛ばすアンデッド。宙に浮いていて、遠くから削ってきます。
    • 石のガーゴイル … 門が半分削れたころに現れる精鋭。岩を投げ、近づけば爪で殴ります。
    • 亡霊騎士（魔界）… 霧のような下半身で漂うアンデッド。呪剣で斬りかかってきます。闇属性なので聖なる力がよく効きます。
    • 業火の魔人（魔界）… 背から炎を噴き上げる魔人。爆発する火炎弾を投げてきます。炎属性なので炎は効きません。氷で。
    • 瘴気蜘蛛（魔界）… 8本脚で素早く迫り、毒液を吐いてきます。足が鈍るので囲まれる前に処理しましょう。
    • 魔狼 … 主を持たない野良の狼。まっすぐ祭壇を目指して走ってきます。

    ボスは門を壊した瞬間に現れます。古代遺跡には炎竜 イグニス、常闇の樹海には魔狼王 フェンリル（とにかく速く、噛みつきが重い）。どちらも体力が桁違いなので、パーティで囲んで削りましょう。

    魔界の最奥には魔王 ヴァルゼオスが待っています。角と翼をもつ人型で、離れていれば破滅の波動、近づけば魔王の剛剣で薙ぎ払ってきます。闇属性なので聖なる力（僧侶の聖光・聖なる槌）が1.8倍で通ります。

    炎竜 イグニスは間合いで攻撃を変えます。離れていれば爆発する竜炎を吐き、近づかれると巨爪で薙ぎ払います。巨体でぶつかった木や柱を薙ぎ倒しながら進むので、隠れていた遮蔽が突然なくなります。さらに歩いた跡に炎が残り、踏んでいる間ずっと焼かれます（炎は数秒で燃え尽きます）。竜の正面と通り道の両方を避けて戦いましょう。

    ステージ「訓練の間」

    はじめての人のための訓練施設です。魔物はいません。マップの中央に木人が並んでいて、攻撃しても反撃されません。壊した木人は数秒で立て直るので、何度でも練習できます。

    画面の左に練習メニューが出ます。案内された操作をそのとおりにやると、次の項目へ進みます。移動・攻撃・詠唱・武器の持ちかえ・火炎瓶・呪印・盾・魔導砲台・ゴーレム・祭壇での補給まで、ひととおり試せば本番のステージで困りません。うまくいかない項目は「この項目をとばす」で先に進めます。

    ステージ「破壊の森」と破壊の杖

    枯れ木と岩だけの静かな森です。障害物は少なく見通しがよいぶん、隠れる場所もありません。

    森の中央の祭壇に💀 破壊の杖が祀られています。近づくだけで拾えて、拾った人が持ち主になります。骨の飾りがついた杖で、その骨の眼が緑に光っています。杖には次の力があります。

    • 拾えるのは人が操るキャラだけです（CPUの仲間は拾いません）。
    • クリック … 前を薙ぎ払う近距離攻撃。長押し … 骨の眼から破滅弾を撃つ遠距離攻撃。
    • どちらも相手の最大HPの4分の3を持っていきます（鎧も盾も効きません）。つまり2発で誰でも倒せます。
    • 味方にも当たります。仲間を巻きこまないよう、撃つ向きに気をつけてください。
    • 杖を持っている間、まわりに緑のフィールドが張られます。飛びこんできた敵の弾はそこで爆発し、持ち主とその仲間は傷つきません。
    • 振り抜いた場所には緑の瘴気がしばらく漂います。連射はできません（ゴーレムの岩塊砲よりさらに遅い）。
    • 持ち主が倒れると、杖は6秒後に祭壇へ戻ります。

    ステージ「常闇の樹海」

    夜が明けない密林のステージです。木と茂みが密生していて視界はほとんど利きません。そしてこの森には、魔物とは別に得体の知れない影が1体だけ棲んでいます。

    影は音に反応します。Shift でダッシュすると足音が響いて気づかれ、攻撃するとさらに遠くから寄ってきます。歩いている限りは、すぐ近くまで行かないかぎり見つかりません。

    倒すことはできません。どんな武器も効かないので、見つかったら逃げるしかありません。そして触れられたら一撃で死にます。追われている間は画面の縁が赤く脈打ち、ミニマップに赤い点が出ます。走って逃げれば足音でずっと追われるので、遮蔽に隠れて歩いて撒くのが賢いやり方です。

    ゴーレムと魔導砲台

    守護ゴーレムは乗り込んで操れる石の巨人です。岩塊砲（爆発・大型に強い）と魔力連弾（連射・雑魚に強い）を撃ち分けられます。数字キーかホイール（スマホは「武器」ボタン）で切り替えてください。魔物側にも魔像ゴーレムがいて、こちらは勝手に暴れます。

    魔導砲台はマップ上に8つ置かれた中立の設備です。近づいてEキー（スマホは「ゴーレム」ボタン）で取り付きます。動けなくなる代わりに光の矢を連射でき、石垣のおかげで被弾も半分になります。先に取り付いた者が使えます。

    隠れる：魔物は壁や石柱の裏にいる相手を見つけられず、正面の視野角の外も見えません。茂みは通り抜けられるのに視線を遮るので、待ち伏せに最適です。ただし至近距離まで近づくと向きに関係なく気づかれます。走ると足音が響くので、忍び寄るときは歩きましょう。

    昼と夜：時間が進むと朝→昼→夕方→夜と移り変わります。夜は視界がぐっと狭まるので奇襲のチャンス、昼は遠くまで見渡せます。

    呪印の罠：足元に描くと約1秒後に起動し、踏んだ敵を吹き飛ばします。味方には見えますが、敵にはすぐ近くに来るまで見えません。ゴーレムにも大ダメージ。

    攻撃直前に盾を構えるとパリィ成功。飛び道具は敵へ跳ね返し、近接攻撃や狼の噛みつきは相手をひるませます。パリィ受付は短く、成功後も約1秒の再使用待ちがあります。通常の盾防御は正面攻撃を軽減しますが、構え中は攻撃不可・移動速度低下。聖銀の鎧と魔法の盾はフィールドで拾うか、祭壇で補給できます。
