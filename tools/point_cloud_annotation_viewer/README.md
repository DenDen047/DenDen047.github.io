# 点群・アノテーションビューア

マルチフレームの点群データとアノテーションデータを可視化するツールです。

## 機能

- **マルチフレーム表示**: 複数の点群ファイルを連続表示
- **アノテーション表示**: KITTI形式のバウンディングボックス表示
- **重心表示**: 重心データの可視化
- **フレーム制御**: 前後移動、長押しによる自動再生
- **カラーマップ**: 4種類の色設定

## 使用方法

1. **点群ディレクトリを選択**: `.bin`ファイルを含むディレクトリ
2. **アノテーションディレクトリを選択** (オプション): `.txt`ファイル（KITTI形式）
3. **重心ファイルディレクトリを選択** (オプション): `.csv`ファイル
4. **Load Data**ボタンをクリック
5. **Prev/Next**ボタンでフレーム移動

## ファイル形式

- **点群**: `.bin`ファイル（x,y,z,intensity の4要素）
- **アノテーション**: `.txt`ファイル（KITTI形式）
- **重心**: `.csv`ファイル（x,y,z の3要素）

## 注意事項

- ファイル名は対応する点群ファイルと一致している必要があります
- アノテーションと重心ファイルはオプションです
- 点群ファイルのみでも可視化可能です
