# 3D点群ビューア

このWebアプリケーションは、`.bin`形式の3D点群データをブラウザ上でインタラクティブに表示し、分析するためのツールです。
Three.jsを利用して3Dレンダリングを行い、ユーザーが点群データを視覚的に理解しやすくするための様々な機能を提供します。

## 主な機能

* **.binファイル読み込み:** ローカルにある`.bin`形式の点群ファイル（各点がX, Y, Z座標と強度を持つfloat32のシーケンス）を読み込んで表示します。
* **3Dインタラクション:**
    * マウス操作（ドラッグ、スクロール、右クリックドラッグ）による視点の回転、ズーム、パンが可能です。
* **点群表示設定:**
    * **点のサイズ調整:** スライダーで表示される点のサイズをリアルタイムに変更できます (最小: 0.01, 最大: 0.50)。
    * **強度フィルタ:** 点群の強度値に基づいて、表示する点の範囲を最小値と最大値のスライダーでフィルタリングできます。
    * **カラーマップ変更:** 点の強度を視覚化するためのカラーマップを複数から選択できます。
        * 白-赤 (デフォルト)
        * グレースケール
        * 虹色
        * 青-黄-赤
* **高度な処理・可視化オプション:**
    * **ボクセル化 (Voxel Grid):**
        * 点群を指定したサイズのボクセルグリッドに分割し、各ボクセルを代表点または立方体で表示します。
        * 「有効にする」チェックボックスで機能をオン/オフできます。
        * 「サイズ」入力フィールドでボクセルのサイズ（メートル単位）を指定できます。
        * 「ボクセルを立方体で表示」チェックボックスをオンにすると、各ボクセルが立方体として描画され、オフの場合はボクセルの中心（または重心）が点として描画されます。立方体表示の場合、背景グリッドもボクセルサイズに連動して更新されます。
    * **Octree化 (Region Octree):**
        * 点群データをOctree構造で空間分割し、指定した深さのリーフノードの代表点（重心と平均強度）を表示します。
        * 「有効にする」チェックボックスで機能をオン/オフできます。
        * 「深さ」入力フィールドでOctreeの最大分割深度（1～10）を指定できます。
        * 「境界ボックス表示 (実範囲)」チェックボックスをオンにすると、点群を含むOctreeの各リーフノード（または指定深さのノード）の実際の点群範囲に基づいたバウンディングボックスが線で描画されます。
* **補助表示:**
    * 座標軸（X:赤, Y:緑, Z:上(青)）を表示します。
    * XY平面のグリッド線を表示します（ボクセル立方体表示時は、ボクセルサイズに連動した動的グリッドを表示）。
* **情報表示:**
    * 読み込んだ点群の総点数と、フィルタリングや処理後に現在表示されている点の数（またはボクセル/Octreeノードの数）を表示します。
* **エラー通知:** ファイル形式エラーや処理中のエラーが発生した場合、ユーザーに通知します。

## 操作方法

1.  **ファイル選択:** 左上の「.bin ファイルを選択」ボタンをクリックし、表示したい`.bin`ファイルを選択します。
2.  **視点操作:**
    * **回転:** マウスの左ドラッグ
    * **ズーム:** マウスホイールのスクロール
    * **パン（移動）:** マウスの右ドラッグ、またはCtrlキーを押しながら左ドラッグ
3.  **各種設定:** 左上のUIパネルから、点のサイズ、強度フィルタ、カラーマップ、ボクセル化オプション、Octree化オプションを適宜変更すると、表示がリアルタイムに更新されます。

## 既知の問題点・今後の拡張可能性

* **パフォーマンス:** 非常に大規模な点群データや、ボクセル/Octree表示で要素数が多い場合、ブラウザのパフォーマンスに影響が出る可能性があります。`THREE.InstancedMesh`などを利用した最適化が考えられます。
* **Octreeの高度な可視化:** 現在のOctree表示は代表点と境界ボックスですが、将来的にはLOD（Level of Detail）表示や、よりインタラクティブなノード探索機能の追加も検討できます。
* **UI/UXの改善:** 各種パラメータの入力方法や、情報表示のさらなる充実。
* **対応フォーマットの拡充:** `.pcd`, `.las`など、他の点群フォーマットへの対応。

## セットアップ

特別なセットアップは不要です。このHTMLファイルをWebブラウザで開くだけで使用できます。
